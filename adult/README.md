# Ai2 Adult Access

This isolated module contains policy/configuration for adult-only companion features.

- Access is for verified adults (18+) only.
- Adult mode is opt-in and should be enforced server-side.
- Romance, flirting and suggestive interactions can be supported within the platform rules.
- Graphic sexual media generation is not enabled by this module.
- No minors are allowed in adult characters, training data or generated scenarios.

Keep age/access state separate from character content so changing adult settings cannot corrupt chats, memories or model configuration.
